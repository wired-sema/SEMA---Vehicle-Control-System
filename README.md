# SIDLAK 2 VCS - Fallback Firmware

**Notice:** This repository contains the **fallback code** for the SIDLAK 2 Vehicle Control System (VCS).

This version features the refactored, stable dual-core architecture (Core 0 Bridge & Core 1 Reflex) designed for the ESP32, ensuring hard real-time safety interlocks, precise hardware control, and WebSockets telemetry.

Use this codebase as a reliable, safe fallback if experimental branches become unstable.
